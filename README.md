# Курсовая работа по алгоритмизации и программированию

## Тема курсовой работы

**«Разработка проекта по вычислению определителя целочисленной матрицы средствами языка C++»**

## Вариант задания

Написать программу, которая позволяет ввести с клавиатуры число `x` типа `unsigned int` и создаёт массив `X` из его битов.

Каждый элемент массива определяется значением бита, симметричного текущему индексу:

```text
X = X[4]
X = X[5][6]
...
X = X[7][8]
```

Программа выводит полученный массив в консоль и находит в нём первый элемент, отличный от `1`.

## Особые условия варианта

- Для исходных чисел используется тип `unsigned short int`, если другой тип не указан отдельно.
- Для числа `x` используется тип `unsigned int`, как указано в задании.
- Арифметические операции `+`, `-`, `*`, `/`, `%` запрещены, если это не оговорено отдельно.
- Для обработки данных применяются побитовые операторы `&`, `|`, `~`, `^`, `<<`, `>>`.
